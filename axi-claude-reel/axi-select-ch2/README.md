- `render_part.sh` / `join_parts.sh`: render the film in three parts and join them with the mix;
- `kit2_api.md`: the reference for video 2's kit additions;
- `mg_ep2_final.json`: the approved motion-graphics spec;
- `sfx/`: the SFX cues.
