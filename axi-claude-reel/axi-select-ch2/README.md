## Project files

`project/` holds the code that builds this video:
- `src/`: the graphics, built into `fx.js` by `build_fx.sh`:
  - `00_head`, `10_kit` and `15_kit2`: the brand kit (video 2 adds the tickets / target / calendar / withdraw symbols,
    the donut, the condition pips, counters, the first-trade chip, skeletons, the shared B-roll world and the comet);
  - `20_studio`: the studio camera, floor light and void masks;
  - `30`–`34`: one file per scene group;
  - `90_main`: the subtitles, the logo bug and the end wipe;
- `fx.js`: the built file;
- `edl_build.py`: the shot list and subtitles (`--srt=` writes the SRT, `--cover` the thumbnail frame);
- `audio_build.py`: the music re-cut, voice and SFX mix (`sfx_lock.json` keeps every cue's sound file fixed);
- `voice_patch/`: how the "$1,000" passage of the voice was restored;
- `render_part.sh` / `join_parts.sh`: render the film in three parts and join them with the mix;
- `kit2_api.md`: the reference for video 2's kit additions;
- `mg_ep2_final.json`: the approved motion-graphics spec;
- `sfx/`: the SFX cues.
