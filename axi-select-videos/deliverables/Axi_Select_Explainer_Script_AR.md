1. سجّل **كل مشهد بشكل منفصل** (انسخ نص المشهد فقط)، حتى تحطه بالضبط على وقت بدايته بالفيديو.

4. الإعدادات المقترحة: Stability ‎45–55% · Similarity ‎75% · Style ‎15–25% · Speed ‎1.0.

6. الفيديو بيه موسيقى خلفية هادئة؛ خلّي الصوت أعلى منها بحوالي 10–12 dB (أو استخدم نسخة الفيديو بدون موسيقى + ملف الموسيقى بشكل منفصل).

> ملاحظة: الكتابة متعمدة حتى ينطقها الذكاء الاصطناعي صح: ماكو «گ»، والأرقام مكتوبة مثل ما تنحچي، و MT4 / MT5 مكتوبة «إم تي فور / إم تي فايف».
