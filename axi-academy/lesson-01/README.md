# Axi Academy — Lesson 01: ما هو الفوركس؟

This lesson uses the same kinetic-typography style as Lesson 17. The animation is synced word by word to the original voice-over, which is **not included**.

- `Lesson01_What_is_Forex.mp4` — final video: 1920×1080, 60 fps, 123.9 s. The soundtrack is **music + sound effects only**; the music already dips wherever the voice speaks.
- **To add your voice-over:** place the original voice file (`new_lesson_1.wav`) so it starts at **00:00:02.000**, at its original level. The first 2 seconds are the brand open.
- **Music:** a new score for this lesson — 104 BPM in C major (Cmaj7 · Am7 · Fmaj7 · G6), with marimba plucks, a broken beat and light swing.
- **Chapters:** ما هو الفوركس؟ · سوق الصرف · قصة جون · الجائحة · المفاجأة · الدرس المستفاد · ابدأ الآن
- **Source files:** `src/` holds the scenes, `audio/synth.py` builds the score (`NOVOICE=1` renders music + SFX only), and `tools/` holds the render scripts. They share the same engine as Lesson 17.
- **Notes:** the rates and amounts on screen are illustrative.
