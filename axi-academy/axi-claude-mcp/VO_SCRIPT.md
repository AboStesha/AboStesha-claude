# نص التعليق الصوتي — ربط Claude بحساب آكسي (9:16)

## قبل التسجيل

- **الموسيقى:** الموسيقى في الفيديوهات منخفضة مسبقاً (−5 dB) في أوقات الكلام المكتوبة أدناه، فالصوت يركب فوقها مباشرة.
- **التوقيت:** ابدأ كل جملة عند الوقت المكتوب جنبها. إذا طالت جملة، احذف كلمة ولا تسرّع الكلام.
- **المستوى:** صوتك بحدود −16 LUFS. الموسيقى ماسترها −17 LUFS.
- **الأسلوب:** فصحى مبسّطة، ودّية وواثقة. الإعلان أسرع وفيه طاقة، والشرح أهدأ وواضح.
- **النطق:**
  - Claude: «كلود».
  - MCP: «إم سي بي».
  - MT5: «إم تي فايف».
  - mcp.axi.com: «إم سي بي دوت آكسي دوت كوم».
  - Add / Connect / Add custom connector: تُقرأ بالإنجليزية كما تظهر في الشاشة.

### ملاحظات امتثال

- لا نقول «ربح» أو «مضمون» أو أي وعد بعائد. الأرقام في الشاشات توضيحية، ومكتوب ذلك في الإعلان.
- الخدمة في مرحلة تجريبية (Alpha) ولحسابات MT5 فقط، ومكتوب ذلك في نهاية الفيديوهين.
- شريط المخاطر يظهر بآخر 3 ثواني من كل فيديو، حسب دليل العلامة.
- «Claude» اسم منتج تملكه Anthropic. استخدمنا الاسم كنص فقط، بدون شعار Anthropic أو Claude.
