# Project instructions

## Skills

For any design, frontend, presentation, or animation work, review the
installed skills in `.claude/skills/` and use the most relevant ones
(for example `impeccable`, `design-taste-frontend`, `high-end-visual-design`,
`animate`, `apple-design`, `review-animations`).

Prefer explicit skill use over generic defaults. When several skills overlap,
pick the one or two that best match the request and say which you used.
