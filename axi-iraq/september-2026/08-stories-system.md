## B. Daily market pulse — mandatory data protocol (per brief)

Every pulse, no exceptions — research CURRENT numbers on the day, never from memory:
1. Pull current price + previous close from a reputable live source; verify against a second source; compute change % yourself.
2. Never mix definitions (current vs close vs weekly). Market closed → say so honestly (weekend frames use Friday close + weekly movement, labeled).
3. If numbers can't be verified: **DATA NOT VERIFIED — DO NOT PUBLISH** (skip the frame, run the education frame instead).

**Template (fill daily):**
```
DATA
Instrument: (rotate: XAUUSD Mon · EURUSD Tue · USD index or oil Wed · GBPUSD/major-of-the-week Thu · weekly close Fri)
Current price: ____   Previous close: ____
Change: ____  Percentage: ____%  Direction: ▲/▼
Data timestamp (UTC): ____   Baghdad time: ____
Primary source: ____  Verification source: ____
Market status: open/closed

COPY
Arabic headline: «الذهب اليوم» style — instrument + one plain fact
Supporting line: one sentence of context (event-linked when true)
Source line: «المصدر: ____ · ساعة بغداد ____»
Disclaimer: «معلومة سوقية للأغراض التعليمية — ليست توصية» + [RISK-AR short]

DESIGN
Layout: file 09 pulse template (dark card, big number, direction arrow, sparkline abstract)
Chart/data treatment: sparkline only — no fake candlesticks with readable invented prices
Animation: number count-up + arrow slide (reusable motion preset)
Interaction: emoji slider or «توقعك؟» poll ONLY on education frames — never framed as prediction advice on data frames
```
