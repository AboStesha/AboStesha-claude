# 05 — Weekly Hero Videos: 5 Concepts, Scores, Production Packs

**System:** one hero Reel per week, 9:16 master (30–40s) + 15s cut + 4:5 feed crop. Every video: 3 thumbnail options (system in file 09), caption with `[RISK-AR]`, paid-media handoff version (clean master, no burned captions, logo-safe margins, Meta CFD-authorization note — see file 02 §C).
**Production doctrine (per brief §4):** storyboard first → shot-by-shot generation (never one-prompt commercials) → real UI only from approved screen recordings → no AI-fabricated numbers → people in the women's/real-life films are real, filmed humans.
**Higgsfield mapping:** cinematic films = image keyframes (Soul/Nano Banana Pro for stills → Seedance 2.0 image-to-video per shot, 9:16); thumbnails via the `youtube-thumbnail-generator` workflow; character consistency via `character-sheet` when a recurring AI persona appears (avoid for humans we can film). Voiceover: record real Iraqi VO — AI voices only for scratch tracks.
**Weekly rule:** before each production, refresh research (what's trending this week in finance Reels) and re-verify every Axi fact used. Full 32-point production packs get finalized in the week's cycle — this file holds the master creative decisions so you're never inventing from zero.
